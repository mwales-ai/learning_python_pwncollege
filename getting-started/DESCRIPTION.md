# Python Crash Course

This module is going to be a bit of a crash course in teaching you a little
bit of python.  Python is a programming language that can run on Windows,
Linux, or Mac.  It's not a bad language to start with because the language
is a very high-level language (you don't need to know the details of processor
instructions, memory management, the very low-level things).

You could probably spend an entire semester learning python in a class, but
often in college, Computer Science majors may just be expected to learn the
language on their own or in a 1-2 hour a week lab class.

You'll learn more python in AP Computer Science Principles class.

Through a series of challenges we will try to guide you through some basic
python.  For this module, there are a couple of online books that would be
helpful references.

* [Automate the Boring Stuff with Python by Sweigart](https://automatetheboringstuff.com/3e/) -
  this book is free to read online, but is available to purchase for Kindle
  or from most bookstores.
* [A Byte of Python by Swaroop Chitlur](https://python.swaroopch.com/) - free
  online
* [Python Tutorial from python.org](https://docs.python.org/3/tutorial/index.html) - This
  one self describes itself as a tutorial for progammers new to python, but not
  for those new to programming
